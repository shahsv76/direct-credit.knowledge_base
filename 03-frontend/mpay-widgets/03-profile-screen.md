# Экран: Паспортные данные (Анкета) (WV)

## Открытие страницы
Страница открывается после успешного ввода СМС-кода (🔗 [Ввод кода подписи](./02-sms-screen.md)).
🔗 [Входные параметры (URL)](./url-params.md) см. на общей странице.

## Сценарий получения информации для отображения
При открытии экрана отправляются следующие запросы:
1.  **`action=step1/form`** — получение структуры формы и предзаполненных данных (модели).
2.  **`action=settings/get-services-texts`** — получение текстов соглашений.
3.  **`action=api/antifraud/pixel`** — антифрод.
4.  **`action=score/getresult`** — циклический опрос результатов скоринга (polling).

## Элементы управления (UI)
> ⚠️ **Валидация:** При незаполненных полях они подсвечиваются красным, а кнопка становится неактивной.

| Название                 | Тип                    | Значение по умолчанию               | Проверка (Валидация)                         | Сценарии                                                |
| ------------------------ | ---------------------- | ----------------------------------- | -------------------------------------------- | ------------------------------------------------------- |
| **Фамилия Имя Отчество** | Input (Text) + Suggest | `model.fio.value` (из `step1/form`) | Паттерн: только кириллица, пробелы, дефисы.  | Вызов подсказок от **DaData** после ввода 4-го символа. |
| **Пол**                  | Radio                  | `model.sex` (из `step1/form`)       | Выбор одного из двух (М/Ж).                  | Yandex-метрика: `eventGeneralCheckboxChange`.           |
| **Дата рождения**        | Input (Date)           | `model.birthday`                    | Маска `DD.MM.YYYY`. Проверка возраста (18+). | Открывается календарь.                                  |
| **Электронная почта**    | Input (Email)          | `model.email`                       | Валидация формата email.                     | Используется для чека.                                  |
| **Дата выдачи паспорта** | Input (Date)           | `model.date_issue`                  | Не может быть в будущем.                     | Открывается календарь.                                  |
| **Кнопка «К шагу 2/2»**  | Button                 | —                                   | Неактивна, пока не заполнены поля.           | См. ниже.                                               |

### Интеграция с DaData (Поле «ФИО»)
При вводе символов отправляется запрос:
**Endpoint:** `POST https://suggestions.dadata.ru/suggestions/api/4_1/rs/suggest/fio/`
*Если DaData не может распознать данные (низкий `qc`), вызывается модальное окно «Мы не смогли найти ваше ФИО» для ручной корректировки.*

## Логика работы кнопки «К шагу 2/2»
1.  Отправка события `eventButtonSubmit` в Яндекс.Метрику.
2.  Вызов **`action=step1/save`** для сохранения данных формы.
3.  Переход на следующий экран (⏳ *название экрана не зафиксировано, предположительно загрузка или выбор банка*).
