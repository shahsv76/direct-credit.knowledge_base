# Экран: Авторизация (WV)

## Открытие страницы
Страница открывается как первый шаг сценария заполнения заявки. 
🔗 [Входные параметры (URL)](./url-params.md) см. на общей странице.

## Сценарий получения информации для отображения
При открытии экрана отправляется следующая последовательность запросов к `widget.php`:
1.  `action=start/start` — инициализация сессии виджета.
2.  `action=config` — загрузка конфигурации (цвета, логотипы).
3.  `action=settings/get-services-texts` — тексты согласий.
4.  `action=calc/programs` — получение списка программ и сроков.
5.  🔗 [`action=auth/form`](../../04-backend/domain-services/mpay/bff-front-api/auth-form.md) — получение структуры полей (schema, model).
6.  `action=customer-agreements/get` — получение текста обязательных согласий.
7.  `action=additional-product-agreements/get` — получение доп. продуктов.
8.  `action=api/antifraud/pixel` — антифрод.

## Логика работы кнопки «Продолжить»
1.  Отправка события `eventButtonSubmit` в Яндекс.Метрику.
2.  Вызов `action=payment-method/save` (сохранение способа оплаты).
3.  Вызов `action=customer-agreements/save` (сохранение согласий).
4.  Вызов 🔗 [`action=sms/send`](../../04-backend/domain-services/mpay/bff-front-api/sms-send.md) (отправка СМС).
5.  При успехе открывается экран 🔗 [Ввод кода подписи](./02-sms-screen.md).
