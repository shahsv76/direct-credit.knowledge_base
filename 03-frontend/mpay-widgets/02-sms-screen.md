# Экран: Ввод кода подписи (WV)

## Открытие страницы
Модальное окно открывается после успешного выполнения метода `sms/send` на предыдущем экране (🔗 [Авторизация](./01-auth-screen.md)).

## Элементы управления (UI)
| Название                             | Тип            | Значение по умолчанию                            | Проверка (Валидация)        | Прочие требования / Сценарии                                                                                                 |
| ------------------------------------ | -------------- | ------------------------------------------------ | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Заголовок**                        | Text           | `"Ввод кода подписи"`                            | —                           | Статичный заголовок.                                                                                                         |
| **Подзаголовок**                     | Text           | `"СМС код отправлен на номер +7 (***) ***-2211"` | —                           | Содержит маскированный номер телефона.                                                                                       |
| **Поле ввода кода**                  | Input (Number) | `""` (пусто)                                     | 6 цифр (6 отдельных ячеек). | ⏳ *Метод, вызываемый при вводе 6-й цифры, не зафиксирован в логах.*                                                          |
| **Кнопка «Отправить СМС-код»**       | Link/Button    | —                                                | —                           | ⏳ *Вызывает повторную отправку (вероятно, `sms/send`). Известно, что API возвращает `delay: 60` (таймер блокировки кнопки).* |
| **Кнопка «Изменить номер телефона»** | Link/Button    | —                                                | —                           | ⏳ *Действие не зафиксировано (вероятно, возврат на экран Авторизации).*                                                      |

## Логика работы
1. **Отображение:** Фронтенд показывает модальное окно с полями для ввода кода.
2. **Ввод кода:** Пользователь вводит 6 цифр. 
   * ⏳ *Какие методы вызываются после ввода 6-й цифры (проверка кода, переход на шаг «Анкета» или ошибка) — в логах не зафиксировано.*
3. **Повторная отправка:** При нажатии на «Отправить СМС-код» запускается таймер (60 секунд), в течение которого кнопка неактивна.
4. **Переход далее:** После успешной проверки кода открывается экран 🔗 [Паспортные данные](./03-profile-screen.md).
