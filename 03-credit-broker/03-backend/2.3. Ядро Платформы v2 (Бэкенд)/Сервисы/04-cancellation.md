## Назначение домена

Домен описывает сценарии прекращения заявки: отмена до авторизации, отмена после авторизации, аннулирование, частичный/полный возврат товара, а также возможность клиента перевыбрать банк.

## Связь с API

| Action                                                      | Что используют сервисы домена                                                                                 |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `cancel/form`                                               | `CancelResolver`, `ReChangeResolver`, `CancelOrderService` — что можно отменить и доступен ли перевыбор банка |
| `cancel/save`                                               | `CancelOrderService`, `Runner\Factory`, `ScansForCancelPreparer` — выполнение отмены                          |
| `cancel/re-change`                                          | `ReChangeResolver`, `CancelTypeQualifier` — перевыбор банка клиентом                                          |
| `cancel/get-step-after`, `cancel/simplified-get-step-after` | `CancelResolver`, `CancelOrderService` — шаг после отмены                                                     |
| `lk/refuse`, `lk/simplified-refuse`                         | `CancelOrderService`, `CancelResolver` — отказ из личного кабинета                                            |
| `bank/get-app-status`                                       | `CancelStatusFabric`, `CancelResolver` — интерпретация статуса с учётом отмены                                |
