## Назначение домена

Домен отвечает за «каркас» оформления заказа: какой бизнес-процесс применяется к заказу, какие шаги и в каком порядке показываются клиенту, можно ли продолжить оформление, как хранятся параметры заказа и как изменяется состав услуг заявки.

## Связь с API

Все методы вызываются через `/api/widget.php?action=<action>` (маршруты — [`RouterProvider.php`](../../../../../newprod.direct-сredit.ru/bitrix/components/dc/online.widget.new/lib/RouterProvider.php)).

| Action                                                           | Что используют сервисы домена                                                                          |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `start/start`                                                    | `ContinueGateService`, `OrderStrategyFactory`, `ActiveOrderService` — старт виджета и определение шага |
| `get-current-step`                                               | `ContinueGateService`, `OrderStrategyFactory` — расчёт текущего шага заказа                            |
| `step1/form`, `step1/save`, `step1/full-form`, `step1/full-save` | `ApplicationStateService`, `ServicesCreater`, `ServicesUpdater`, `OrderParamsService`                  |
| `step2/form`, `step2/save`, `step3/form`, `step3/save`           | `ApplicationStateService`, `ServiceFinder`, `ServicesUpdater`, `AccreditationService`                  |
| `calc/programs`, `calc/save`                                     | `OrderParamsService`, `ServicesCreater` (расчёт программ и сохранение параметров)                      |
| `status/get`                                                     | `ApplicationStateService`                                                                              |
| `final/get`                                                      | `ApplicationStateService`, `MemoResolver`, `ContinueGateService`                                       |
| `feedback/form`, `feedback/call`                                 | `ApplicationStateService`, `OrderParamsService` (контекст заявки в обращении)                          |
