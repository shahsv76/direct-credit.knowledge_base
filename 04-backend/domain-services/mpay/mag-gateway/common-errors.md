# Общие ошибки (MAG)

## Форматы ошибок
В зависимости от источника ошибки, MAG может возвращать разные JSON-структуры.

* **Базовая ошибка [ErrorResponse](./api/general-dto.md#errorresponsedto)** используется, когда MAG сам формирует ответ (например, при внутренних ошибках чтения/парсинга тела запроса, либо когда внешний сервис вернул простую ошибку без дополнительных полей).
* **Расширенная ошибка [ErrorResponse2](./api/general-dto.md#errorresponse2dto)** используется, когда MAG сам формирует ответ с информацией о блокировке (например, в методе `resend`), или когда он пробрасывает ответ от внешнего сервиса, в котором есть поле `blockToTime` (например, при превышении лимитов OTP или блокировке клиента).
* **Ошибки внешних сервисов (Pass-through)**. В большинстве методов при ошибке вызова внешнего сервиса (Authentication, OTP, Authorization и др.) MAG **не пересобирает** ответ, а транслирует его клиенту «как есть» (с оригинальным HTTP-статусом и телом). Формат такого ответа определяется контрактом конкретного внешнего сервиса.

## Общие коды ответов

| Код ответа | Описание              | Типовая причина                                                             |
| ---------- | --------------------- | --------------------------------------------------------------------------- |
| `200`      | OK                    | Успешное выполнение запроса                                                 |
| `201`      | CREATED               | Успешное создание сущности (например, OTP-кода или сессии)                  |
| `400`      | BAD_REQUEST           | Неверный формат запроса, невалидные данные или ошибка валидации             |
| `401`      | UNAUTHORIZED          | Отсутствует или недействителен токен авторизации                            |
| `403`      | FORBIDDEN             | Доступ запрещён (например, превышен лимит запросов или клиент заблокирован) |
| `404`      | NOT_FOUND             | Запрашиваемый ресурс не найден                                              |
| `429`      | TOO_MANY_REQUESTS     | Превышено количество попыток (пробрасывается от внешнего сервиса)           |
| `500`      | INTERNAL_SERVER_ERROR | Внутренняя ошибка MAG или ошибка вызова внешнего сервиса                    |
