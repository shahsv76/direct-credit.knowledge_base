# Общие заголовки (MAG)

Все методы MAG используют единый набор HTTP-заголовков.

| Название        | Тип    | Обязательность | Описание                   | Пример             |
| --------------- | ------ | -------------- | -------------------------- | ------------------ |
| `Content-Type`  | String | Да             | Тип передаваемых данных    | `application/json` |
| `Authorization` | String | Да             | Bearer-токен               | `Bearer eyJ...`    |
| `X-Request-Id`  | String | Нет            | ID запроса для трассировки | `550e8400-...`     |
| `User-Agent`    | String | Нет            | Клиентское приложение      | `MobileApp/1.0`    |
