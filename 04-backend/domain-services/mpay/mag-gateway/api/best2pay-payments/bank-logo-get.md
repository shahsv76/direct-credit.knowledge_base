# GET /api/v1/contract/bank/logo/get (MAG)

## История изменений

## Описание
| Тип запроса | Название метода | Описание метода                                                                                                     | URL                              | Тип  |
| ----------- | --------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------- | ---- |
| GET         | GetBankLogo     | Возвращает логотип банка в виде изображения, чтобы интерфейс мог показать его рядом с договором или способом оплаты | `/api/v1/contract/bank/logo/get` | SYNC |

Метод используется интерфейсом для отрисовки карточки банка: MAG запрашивает изображение у платёжного шлюза и отдаёт его клиенту как есть.

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Query
| Название   | Тип    | Обязательность | Описание  | Пример |
| ---------- | ------ | -------------- | --------- | ------ |
| `bankCode` | String | Да             | Код банка | `otp`  |

### Body
Тело запроса не используется.

## Выходные параметры
Ответ — бинарное изображение, а не JSON. В заголовке ответа MAG проставляет `Content-Type: image/webp`.

| Название    | Тип    | Обязательность | Описание                                    | Пример         |
| ----------- | ------ | -------------- | ------------------------------------------- | -------------- |
| Тело ответа | Binary | Да             | Содержимое файла изображения в формате WebP | `RIFF....WEBP` |

## Коды ответа
| Код ответа | Описание              | Причина                                                             |
| ---------- | --------------------- | ------------------------------------------------------------------- |
| `200`      | OK                    | Изображение получено                                                |
| `400`      | BAD_REQUEST           | Не передан параметр `bankCode`                                      |
| `500`      | INTERNAL_SERVER_ERROR | Платёжный шлюз не вернул изображение или ответ не удалось прочитать |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Логика работы
1. **Приём запроса:** MAG читает код банка из query-параметра. Если код не передан, возвращается `400` с описанием ошибки в общем формате.
2. **Внешний вызов:** MAG запрашивает у платёжного шлюза изображение логотипа по коду банка.
3. **Ответ:** MAG передаёт клиенту изображение и код ответа шлюза, устанавливая тип содержимого `image/webp`.

## Request
```bash
curl -X GET "https://gateway.direct-pay.ru/api/v1/contract/bank/logo/get?bankCode=otp" \
  -H "Authorization: Bearer <token>" \
  --output logo.webp
```

## Response
`200 OK`, `Content-Type: image/webp`

```text
<бинарное содержимое изображения WebP>
```

При отсутствии параметра:

```json
{
  "meta": {
    "Accept": "KO",
    "Error": "bankCode is empty"
  }
}
```
