# GET /api/v1/payment/prepayment (MAG)

## История изменений
| Дата       | Задача                                                 | Автор                                                                            | Изменение                             |
| ---------- | ------------------------------------------------------ | -------------------------------------------------------------------------------- | ------------------------------------- |
| 23.10.2026 | [CASH-4817a](https://jira.mvideo.ru/browse/CASH-4817a) | [Еременко Светлана Александровна(ДК)](https://wiki.mvideo.ru/display/~SEremenko) | Создание документации через агента ИИ |

## Описание
| Тип запроса | Название метода | Описание метода                                                                                                                        | URL                          | Тип  |
| ----------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | ---- |
| GET         | GetPrepayment   | Возвращает данные для экрана оплаты по заявке: договор, суммы к оплате и комиссию, реквизиты банка, данные клиента и сохранённые карты | `/api/v1/payment/prepayment` | SYNC |

Интерфейс использует метод, чтобы показать клиенту всё, что нужно для принятия решения об оплате: сколько платить, какая комиссия, на какой счёт и с какой карты можно заплатить.

| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Query
| Название                | Тип     | Обязательность | Описание                                                                                                                    | Пример    |
| ----------------------- | ------- | -------------- | --------------------------------------------------------------------------------------------------------------------------- | --------- |
| `accountRequestID`      | String  | Да             | Идентификатор заявки на кредит                                                                                              | `12345`   |
| `repaymentTypeCode`     | String  | Нет            | Тип погашения (см. [`enums.md`](./enums.md#коды-типов-погашения)). Если передан, запрос учитывается как запрос на погашение | `EARLY`   |
| `comfortablePaymentKop` | Integer | Нет            | Комфортная для клиента сумма платежа в копейках. Если передано нечисловое значение — ошибка `400`                           | `1250000` |

### Body
Тело запроса не используется. Идентификаторы клиента и партнёра берутся из сессии ([`GeneralData`](./general-dto.md#generaldata)); в качестве идентификатора клиента передаётся исходный идентификатор до подмены.

## Коды ответа
| Код ответа    | Описание                        | Причина                                                                                      |
| ------------- | ------------------------------- | -------------------------------------------------------------------------------------------- |
| `200`         | OK                              | Данные к оплате получены                                                                     |
| `400`         | BAD_REQUEST                     | В сессии нет данных клиента, `comfortablePaymentKop` не является числом                      |
| `4xx` / `5xx` | Код сервиса проведения платежей | Сервис проведения платежей вернул ошибку — MAG передаёт его код ответа клиенту без изменений |
| `502`         | BAD_GATEWAY                     | Не удалось установить соединение с сервисом проведения платежей                              |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Метрика
| Параметр        | Значение                                                                                  |
| --------------- | ----------------------------------------------------------------------------------------- |
| **Имя метрики** | `MetricPaymentsRequest`, а при указании типа погашения — `MetricRepaymentPaymentsRequest` |
| **Топик**       | Метрики MAG (`metrics-client`)                                                            |
| **vendor**      | `mpay-api-gateway (handler.Payment.GetPrepayment)`                                        |

В метрике передаются телефон клиента, идентификаторы клиента и партнёра, код типа предложения, тип погашения и код ответа.

## Логика работы
1. **Проверка сессии:** если данных клиента нет, возвращается `400`.
2. **Разбор параметров:** MAG читает номер заявки, тип погашения и комфортную сумму. Нечисловая комфортная сумма приводит к ошибке `400`.
3. **Выбор метрики:** если указан тип погашения, запрос считается запросом на погашение и учитывается отдельной метрикой.
4. **Внешний вызов:** MAG передаёт сервису проведения платежей номер заявки, тип погашения, комфортную сумму и идентификаторы клиента и партнёра.
5. **Обработка ошибки:** если сервис вернул ошибку, MAG передаёт клиенту его код ответа и фиксирует ошибку в метрике.
6. **Ответ:** MAG возвращает договор, суммы, реквизиты, данные клиента и сохранённые карты и отправляет метрику с кодом типа предложения из ответа.

## Request
```bash
curl -X GET "https://gateway.direct-pay.ru/api/v1/payment/prepayment?accountRequestID=12345&repaymentTypeCode=EARLY&comfortablePaymentKop=1250000" \
  -H "Authorization: Bearer <token>"
```
