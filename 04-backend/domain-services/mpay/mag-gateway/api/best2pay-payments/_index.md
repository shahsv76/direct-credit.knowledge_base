# best2pay-payments

Группа методов **Best2Pay & Payments API** сервиса `mpay-api-gateway` (MAG). Отвечает за проведение платежей по договорам клиента: получение ссылки на платёжную форму Best2Pay, расчёт суммы к оплате и комиссии, оплату сохранённой картой, оформление заявки на досрочное погашение, логотипы банков и историю операций клиента.

> 💡 **Главная особенность группы.** MAG не показывает платёжную форму самостоятельно: в методах Best2Pay он **возвращает URL для редиректа пользователя на шлюз Best2Pay**. Клиент переходит по этой ссылке и оплачивает договор на стороне шлюза.

## Как это работает

1. **Выбор сценария оплаты.** Партнёрский интерфейс запрашивает ссылку на оплату одним из трёх способов: по идентификатору платежа (v1), по номеру договора в банке (v2) или по номеру заявки (v3).
2. **Подготовка данных.** MAG собирает данные договора, клиента и платежа из внутренних сервисов и передаёт их платёжному шлюзу.
3. **Редирект.** В ответе приходит ссылка на платёжную форму Best2Pay. Пользователь переходит по ней и завершает оплату на стороне шлюза.
4. **Досрочное погашение.** Отдельным сценарием оформляется заявка на досрочное погашение, а метод погашения возвращает ссылку и суммы (сумма погашения, комиссия, итог).
