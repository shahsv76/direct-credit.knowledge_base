# ENUM и константы (Best2Pay & Payments)

## Подписи статусов операций

Используются в методе [`GET /api/v1/payment/history`](./payment-history.md): код состояния операции, который приходит из сервиса проведения платежей, MAG заменяет понятной клиенту подписью.

| Код состояния (`operationState`) | Подпись в ответе MAG |
| -------------------------------- | -------------------- |
| `APPROVED`                       | Принят               |
| `REJECTED`                       | Отклонён             |
| `DELIVERED`                      | В обработке          |
| `REGISTERED`                     | В обработке          |
| Любое другое значение или пусто  | В обработке          |

> ⚠️ Для кода `DELIVERING` в справочнике MAG ключ задан с завершающим пробелом, поэтому значение не распознаётся и попадает в значение по умолчанию — «В обработке». На отображение это не влияет, но при доработке справочника пробел нужно убрать.

## Нормализация кода банка

Правило применяется в методах [`POST /api/v2/bestToPay`](./payment-url-v2.md) и [`POST /api/v3/bestToPay`](./payment-url-v3.md) перед отправкой данных платёжному шлюзу: если у договора ОТП Банка или Сбербанка номер счёта клиента относится к ссудному счёту, MAG подменяет код банка и очищает номер счёта, чтобы шлюз предложил клиенту корректный способ оплаты.

| Код банка в договоре | Условие по номеру счёта клиента    | Код банка, который уходит в шлюз | Номер счёта клиента |
| -------------------- | ---------------------------------- | -------------------------------- | ------------------- |
| `otp`, `otpfinans`   | начинается с `407` или не заполнен | `otpfinans`                      | очищается           |
| `otp`, `otpfinans`   | начинается с `408`                 | `otp`                            | без изменений       |
| `fastb`, `scom`      | начинается с `407`                 | `fastb`                          | очищается           |
| Любой другой         | —                                  | без изменений                    | без изменений       |

## Константы проведения платежа

| Название           | Значение                                         | Описание                                                                                       |
| ------------------ | ------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `RUB`              | `643`                                            | Код валюты платежа (российский рубль), передаётся шлюзу в методе v1                            |
| `transactionID`    | `228`                                            | Внутренний идентификатор транзакции, который MAG передаёт шлюзу в методах v2 и v3              |
| `ConsumerID`       | `mf-gateway`                                     | Идентификатор потребителя Accounting при создании заявки на досрочное погашение                |
| `Source`           | `mf`                                             | Источник заявки на досрочное погашение, который MAG проставляет всегда                         |
| `CreatedBy`        | `mpay_api_gateway`                               | Признак системы-инициатора при чтении данных клиента                                           |
| `CreatedByOp` (v3) | `requestID` из сессии, иначе `/api/v3/bestToPay` | Идентификатор операции-инициатора в методе v3                                                  |
| `DescriptionGood`  | `Оплата кредита`                                 | Назначение платежа, которое MAG передаёт шлюзу                                                 |
| `PartnerId`        | `dcpay-mobile`                                   | Партнёр, для которого в методе v2 идентификаторы клиента и партнёра берутся из данных договора |

## Коды типов погашения

| Название            | Значения      | Описание                                                                                                                                       |
| ------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `repaymentTypeCode` | Строковый код | Тип погашения (полное или частичное досрочное погашение, платёж по графику и т. п.). Справочник ведётся на стороне сервиса проведения платежей |

> ⚠️ MAG не проверяет `repaymentTypeCode` по закрытому списку: значение передаётся как строка, а неизвестные коды обрабатывает внешний сервис.
