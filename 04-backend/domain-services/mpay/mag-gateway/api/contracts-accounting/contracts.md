## Описание
| Тип запроса | Название метода | Описание метода                                                                                                        | URL                 | Тип  |
| ----------- | --------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------- | ---- |
| GET         | GetContracts    | Возвращает договоры клиента с обязательной фильтрацией хотя бы по одному признаку: типу предложения, статусу или банку | `/api/v1/contracts` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Query
| Название           | Тип           | Обязательность | Описание                | Пример                              |
| ------------------ | ------------- | -------------- | ----------------------- | ----------------------------------- |
| `offerTypeCodes[]` | Array<String> | Нет*           | Коды типов предложений  | `offerTypeCodes[]=MFO_CASH`         |
| `statusCodes[]`    | Array<String> | Нет*           | Коды статусов договоров | `statusCodes[]=AGREEMENT_AUTORIZED` |
| `bankCodes[]`      | Array<String> | Нет*           | Коды банков             | `bankCodes[]=otp`                   |

\* Хотя бы один из фильтров должен быть заполнен, иначе MAG вернёт `400`. Значения можно передавать в формате массива (`bankCodes[]=otp&bankCodes[]=sber`) или строкой с запятыми (`bankCodes=otp,sber`).

### Body
Тело запроса не используется. Данные клиента, партнёра и список связанных клиентов берутся из сессии ([`GeneralData`](./general-dto.md#generaldata)).

## Выходные параметры
Ответ Accounting Service проксируется без преобразования: MAG передаёт фильтры и возвращает полученный список договоров.

| Название                 | Тип    | Обязательность | Описание                                                                                                                                                | Пример                |
| ------------------------ | ------ | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| Ответ Accounting Service | Object | Да             | Список договоров с атрибутами `bankContractNum`, `bankCode`, `offerTypeCode`, `status`, `dateConfirm`. Точная структура определяется Accounting Service | `{ "contracts": [] }` |

> ⚠️ Если внешний сервис вернул ошибку, MAG возвращает её код ответа и тело без изменений.

## Коды ответа
| Код ответа | Описание              | Причина                                                    |
| ---------- | --------------------- | ---------------------------------------------------------- |
| `200`      | OK                    | Список договоров получен                                   |
| `400`      | BAD_REQUEST           | В сессии нет данных клиента или не заполнен ни один фильтр |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка API Accounting или чтения ответа                    |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Логика работы
1. **Приём и валидация:** MAG проверяет наличие сессионных данных и разбирает фильтры из query-параметров (поддерживаются оба формата: массив и строка с запятыми).
2. **Проверка фильтров:** если все три фильтра пусты — возвращает `400`.
3. **Внешний вызов:** передаёт в API Accounting идентификаторы клиента и партнёра, телефон, связанных клиентов и фильтры.
4. **Формирование ответа:** возвращает ответ внешнего сервиса клиенту без преобразования, сохраняя его код ответа.

## Request
```bash
curl -X GET "https://gateway.direct-pay.ru/api/v1/contracts?statusCodes[]=AGREEMENT_AUTORIZED&bankCodes[]=otp" \
  -H "Authorization: Bearer <token>"
```
