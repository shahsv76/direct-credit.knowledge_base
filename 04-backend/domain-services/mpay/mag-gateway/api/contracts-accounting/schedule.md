## Описание
| Тип запроса | Название метода | Описание метода                                                                                                                    | URL                | Тип  |
| ----------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------ | ---- |
| GET         | GetSchedule     | Возвращает график платежей по заявке на кредит — используется до оформления договора, когда номер договора в банке ещё не присвоен | `/api/v1/schedule` | SYNC |

| ------------------ | ------ | -------------- | ------------------------------ | ------- |
| `accountRequestID` | String | Да             | Идентификатор заявки на кредит | `12345` |

Тело запроса не используется.

## Выходные параметры
Ответ API Schedule проксируется без преобразования.

| Название           | Тип    | Обязательность | Описание                                                              | Пример                    |
| ------------------ | ------ | -------------- | --------------------------------------------------------------------- | ------------------------- |
| Ответ API Schedule | Object | Да             | График платежей по заявке. Точная структура определяется API Schedule | `{ "schedule": { ... } }` |

## Коды ответа
| Код ответа | Описание              | Причина                                |
| ---------- | --------------------- | -------------------------------------- |
| `200`      | OK                    | График получен                         |
| `400`      | BAD_REQUEST           | Параметры запроса не удалось разобрать |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка API Schedule или чтения ответа  |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Логика работы
1. **Приём и валидация:** MAG разбирает query-параметры в структуру запроса. Если разобрать не удалось — возвращает `400`.
2. **Внешний вызов:** передаёт идентификатор заявки в API Schedule.
3. **Формирование ответа:** возвращает ответ внешнего сервиса без преобразования, сохраняя его код ответа.

## Request
```bash
curl -X GET "https://gateway.direct-pay.ru/api/v1/schedule?accountRequestID=12345" \
  -H "Authorization: Bearer <token>"
```

## Response
`200 OK`

```json
{
  "schedule": {
    "accountRequestID": "12345",
    "payments": [
      {
        "planDate": "2026-11-05",
        "planAmountKop": 1250000
      }
    ]
  }
}
```
