# ENUM и константы (Contracts & Accounting)

## Признак успеха в ответе (`meta.Accept`)

| Название | Значения   | Описание                                                                                                         |
| -------- | ---------- | ---------------------------------------------------------------------------------------------------------------- |
| `Accept` | `OK`, `KO` | Признак успешной обработки запроса на стороне MAG и внешних сервисов. `KO` сопровождается текстом в `meta.Error` |

## Идентификаторы и коды

| Название           | Значение       | Описание                                                                                                                                     |
| ------------------ | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `DCPAY_PARTNER_ID` | `dcpay-mobile` | Идентификатор партнёра, для которого MAG подменяет `clientID` на номер телефона клиента (Client Reader) и строит график через Client Mapping |
| `bankCodeDcPay`    | `dcpay`        | Код банка, договоры которого исключаются из ответа графика платежей для партнёра `dcpay-mobile`                                              |

## Константы фильтрации договоров

Значения по умолчанию для фильтров, которые MAG передаёт в API Accounting. Настраиваются через переменные окружения (см. [Конфигурацию (MAG)](../../config.md)).

| Название         | Env                                   | Значение по умолчанию | Описание                                |
| ---------------- | ------------------------------------- | --------------------- | --------------------------------------- |
| `StatusCodes`    | `ACCOUNTING_FILTERS_STATUS_CODES`     | `AGREEMENT_AUTORIZED` | Статусы договоров, разрешённые к показу |
| `PartnerIDs`     | `ACCOUNTING_FILTERS_PARTNER_IDS`      | — (пусто)             | Ограничение по партнёрам                |
| `OfferTypeCodes` | `ACCOUNTING_FILTERS_OFFER_TYPE_CODES` | — (пусто)             | Ограничение по типам предложений        |
| `BankCodes`      | `ACCOUNTING_FILTERS_BANK_CODES`       | — (пусто)             | Ограничение по банкам                   |

## Коды типов предложений и статусов

| Название        | Значения      | Описание                                                                                                                                  |
| --------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `offerTypeCode` | Строковый код | Тип предложения (например, кредит наличными, POS-кредит). Справочник ведётся на стороне Accounting Service                                |
| `status`        | Строковый код | Статус договора или согласия. Справочник ведётся на стороне Accounting Service, значение по умолчанию для фильтра — `AGREEMENT_AUTORIZED` |

> ⚠️ MAG не валидирует значения `offerTypeCode` и `status` по закрытому списку: они передаются как строки, а неизвестные значения обрабатывает Accounting Service.
