## Описание
| Тип запроса | Название метода | Описание метода                                                                                    | URL                      | Тип  |

| POST        | ContractsReadV2 | Возвращает договоры клиента в формате MFO с возможностью отобрать договоры одного типа предложения | `/api/v2/contracts/read` | SYNC |

### Body
| Название        | Тип    | Обязательность | Описание                                                                       | Пример     |

| `OfferTypeCode` | String | Нет            | Код типа предложения. Если передан, в ответ попадут только договоры этого типа | `MFO_CASH` |

| `payload.Contracts`                                                 | Array<[AccountingContractItem](./general-dto.md#accountingcontractitem)> | Да             | Список договоров клиента                         | `[{ "bankContractNum": "OTP-2026-000123" }]` |

## Коды ответа
| Код ответа | Описание              | Причина                                                        |
| ---------- | --------------------- | -------------------------------------------------------------- |
| `200`      | OK                    | Договоры получены (код ответа Accounting Service проксируется) |
| `400`      | BAD_REQUEST           | В сессии отсутствуют данные клиента                            |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка API Accounting, чтения или разбора ответа               |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Логика работы
1. **Приём и валидация:** MAG проверяет наличие сессионных данных клиента и валидирует необязательный параметр `OfferTypeCode`.
2. **Выбор клиента:** если в сессии передан `mfoClientId`, он используется как идентификатор клиента.
3. **Внешний вызов:** запрашивает договоры у API Accounting, передавая идентификаторы клиента и партнёра.
4. **Фильтрация:** если `OfferTypeCode` указан, MAG оставляет только договоры этого типа предложения; иначе возвращает все полученные договоры.
5. **Формирование ответа:** приводит ответ внешнего сервиса к формату MFO (`meta` + `payload.Contracts`) и возвращает клиенту.

## Request
```bash
curl -X POST "https://gateway.direct-pay.ru/api/v2/contracts/read" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{ "OfferTypeCode": "MFO_CASH" }'
```
