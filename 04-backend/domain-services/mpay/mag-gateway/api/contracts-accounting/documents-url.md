# GET /api/v1/documents/url (MAG)

## История изменений
| Дата       | Задача                                               | Автор                                                                            | Изменение                             |
| ---------- | ---------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------- |
| 22.10.2026 | [CASH-4817](https://jira.mvideo.ru/browse/CASH-4817) | [Еременко Светлана Александровна(ДК)](https://wiki.mvideo.ru/display/~SEremenko) | Создание документации через агента ИИ |

## Описание
| Тип запроса | Название метода           | Описание метода                                                                                                      | URL                     | Тип  |
| ----------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------- | ---- |
| GET         | GetPackageDocsByRequestId | Возвращает временную ссылку на пакет документов по заявке, чтобы клиент мог скачать или открыть договорные документы | `/api/v1/documents/url` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Query
| Название    | Тип    | Обязательность | Описание                                                | Пример  |
| ----------- | ------ | -------------- | ------------------------------------------------------- | ------- |
| `requestID` | String | Да             | Идентификатор заявки, по которой нужен пакет документов | `12345` |

### Body
Тело запроса не используется.

## Выходные параметры
Ответ API Accounting проксируется без преобразования.

| Название  | Тип     | Обязательность | Описание                              | Пример                               |
| --------- | ------- | -------------- | ------------------------------------- | ------------------------------------ |
| `message` | String  | Да             | Временная ссылка на пакет документов  | `https://docs.example/package/12345` |
| `status`  | Boolean | Да             | Признак успешного формирования ссылки | `true`                               |

## Коды ответа
| Код ответа | Описание              | Причина                                                        |
| ---------- | --------------------- | -------------------------------------------------------------- |
| `200`      | OK                    | Ссылка сформирована                                            |
| `400`      | BAD_REQUEST           | В сессии отсутствуют данные клиента или не передан `requestID` |
| `404`      | NOT_FOUND             | Пакет документов по заявке не найден (код проксируется)        |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка API Accounting или чтения ответа                        |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Внешние сервисы
| Сервис           | URL (env)            | Метод | Эндпоинт                                      |
| ---------------- | -------------------- | ----- | --------------------------------------------- |
| API Accounting ⏳ | `API_ACCOUNTING_URL` | GET   | `/api/v1/documents/url?requestID={requestID}` |

## Метрика
| Параметр        | Значение                                                |
| --------------- | ------------------------------------------------------- |
| **Имя метрики** | не отправляется — бизнес-метрика в хендлере отсутствует |
| **Топик**       | —                                                       |
| **vendor**      | —                                                       |

## Логика работы
1. **Приём и валидация:** MAG проверяет наличие сессионных данных клиента и обязательного параметра `requestID`. Если чего-то не хватает — возвращает `400`.
2. **Внешний вызов:** запрашивает у API Accounting временную ссылку на пакет документов по заявке.
3. **Формирование ответа:** возвращает ответ внешнего сервиса без преобразования, сохраняя его код ответа.

## Request
```bash
curl -X GET "https://gateway.direct-pay.ru/api/v1/documents/url?requestID=12345" \
  -H "Authorization: Bearer <token>"
```

## Response
`200 OK`

```json
{
  "message": "https://docs.example/package/12345",
  "status": true
}
```
