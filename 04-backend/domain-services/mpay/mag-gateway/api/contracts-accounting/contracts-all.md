## Описание
| Тип запроса | Название метода | Описание метода                                                                                        | URL                     | Тип  |
| ----------- | --------------- | ------------------------------------------------------------------------------------------------------ | ----------------------- | ---- |
| GET         | GetContractsAll | Возвращает все договоры клиента, включая закрытые и архивные, с необязательной фильтрацией по статусам | `/api/v1/contracts/all` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Query
| Название        | Тип           | Обязательность | Описание                                                               | Пример                 |
| --------------- | ------------- | -------------- | ---------------------------------------------------------------------- | ---------------------- |
| `statusCodes[]` | Array<String> | Нет            | Коды статусов договоров. Несколько значений объединяются через запятую | `statusCodes[]=CLOSED` |

### Body
Тело запроса не используется. Данные клиента, партнёра, телефона и связанных клиентов берутся из сессии ([`GeneralData`](./general-dto.md#generaldata)).

## Выходные параметры
Ответ Accounting Service проксируется без преобразования.

| Название    | Тип                                                                      | Обязательность | Описание                                    | Пример                                       |
| ----------- | ------------------------------------------------------------------------ | -------------- | ------------------------------------------- | -------------------------------------------- |
| `contracts` | Array<[AccountingContractItem](./general-dto.md#accountingcontractitem)> | Да             | Список всех договоров (открытых и закрытых) | `[{ "bankContractNum": "OTP-2025-000987" }]` |

## Коды ответа
| Код ответа | Описание              | Причина                                 |
| ---------- | --------------------- | --------------------------------------- |
| `200`      | OK                    | Список договоров получен                |
| `400`      | BAD_REQUEST           | В сессии отсутствуют данные клиента     |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка API Accounting или чтения ответа |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Логика работы
1. **Приём и валидация:** MAG проверяет наличие сессионных данных и разбирает необязательный фильтр статусов.
2. **Подготовка запроса:** объединяет несколько статусов в строку через запятую и добавляет связанных клиентов.
3. **Внешний вызов:** запрашивает у API Accounting все договоры клиента и партнёра.
4. **Формирование ответа:** возвращает ответ внешнего сервиса без преобразования, сохраняя его код ответа.

## Request
```bash
curl -X GET "https://gateway.direct-pay.ru/api/v1/contracts/all?statusCodes[]=CLOSED" \
  -H "Authorization: Bearer <token>"
```

```json
{

      "bankCode": "otp",
      "status": "CLOSED",
      "dateConfirm": "2025-03-12"
    }
  ]
}
```
