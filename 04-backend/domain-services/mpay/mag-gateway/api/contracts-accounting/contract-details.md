# GET /api/v1/contract (MAG)

## История изменений

## Описание
| Тип запроса | Название метода    | Описание метода                                                               | URL                | Тип  |
| ----------- | ------------------ | ----------------------------------------------------------------------------- | ------------------ | ---- |
| GET         | GetContractDetails | Возвращает подробную информацию о договоре по идентификатору заявки на кредит | `/api/v1/contract` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Query
| Название           | Тип    | Обязательность | Описание                                                                  | Пример  |
| ------------------ | ------ | -------------- | ------------------------------------------------------------------------- | ------- |
| `accountRequestID` | String | Да             | Идентификатор заявки на кредит, по которому запрашиваются детали договора | `12345` |

### Body
Тело запроса не используется.

## Выходные параметры
Ответ Accounting Service проксируется без преобразования.

| Название                 | Тип    | Обязательность | Описание                                                                                                     | Пример                    |
| ------------------------ | ------ | -------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------- |
| Ответ Accounting Service | Object | Да             | Детали договора: банк, номер договора, суммы, срок, статус. Точная структура определяется Accounting Service | `{ "contract": { ... } }` |

## Коды ответа
| Код ответа | Описание              | Причина                                 |
| ---------- | --------------------- | --------------------------------------- |
| `200`      | OK                    | Детали договора получены                |
| `400`      | BAD_REQUEST           | Параметры запроса не удалось разобрать  |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка API Accounting или чтения ответа |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Логика работы
1. **Приём и валидация:** MAG разбирает query-параметры в структуру запроса. Если разобрать не удалось — возвращает `400`.
2. **Внешний вызов:** передаёт идентификатор заявки в API Accounting.
3. **Формирование ответа:** возвращает ответ внешнего сервиса без преобразования, сохраняя его код ответа.

> ℹ️ В отличие от остальных методов группы, этот метод не проверяет наличие сессионных данных: идентификация выполняется на этапе проверки токена.

## Request
```bash
curl -X GET "https://gateway.direct-pay.ru/api/v1/contract?accountRequestID=12345" \
  -H "Authorization: Bearer <token>"
```
