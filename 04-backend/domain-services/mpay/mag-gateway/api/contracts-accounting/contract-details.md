## Описание

| ----------- | ------------------ | ----------------------------------------------------------------------------- | ------------------ | ---- |
| GET         | GetContractDetails | Возвращает подробную информацию о договоре по идентификатору заявки на кредит | `/api/v1/contract` | SYNC |

### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Query
| Название           | Тип    | Обязательность | Описание                                                                  | Пример  |
| ------------------ | ------ | -------------- | ------------------------------------------------------------------------- | ------- |
| `accountRequestID` | String | Да             | Идентификатор заявки на кредит, по которому запрашиваются детали договора | `12345` |

### Body
Тело запроса не используется.

## Выходные параметры
Ответ Accounting Service проксируется без преобразования.

| Название                     | Тип     | Обязательность | Описание                       | Пример                 |
| ---------------------------- | ------- | -------------- | ------------------------------ | ---------------------- |
| `contract`                   | Object  | Да             | Данные договора                | `{ ... }`              |
| `contract.bankCode`          | String  | Да             | Код банка                      | `otp`                  |
| `contract.appID`             | String  | Да             | Код кредитного продукта банка  | `OTP-CASH`             |
| `contract.clientAccountNum`  | String  | Нет            | Номер счёта клиента            | `40817810099910004312` |
| `contract.bankContractNum`   | String  | Да             | Номер договора в банке         | `OTP-2026-000123`      |
| `contract.dateConfirm`       | String  | Да             | Дата подтверждения договора    | `2026-10-01`           |
| `contract.termMonth`         | Integer | Да             | Срок договора в месяцах        | `12`                   |
| `contract.contractAmountKop` | Integer | Да             | Сумма договора в копейках      | `15000000`             |
| `contract.monthlyAmountKop`  | Integer | Да             | Ежемесячный платёж в копейках  | `1250000`              |
| `contract.clientID`          | String  | Да             | Идентификатор клиента          | `client-123`           |
| `contract.partnerID`         | String  | Да             | Идентификатор партнёра         | `dcpay-mobile`         |
| `contract.createdBy`         | String  | Нет            | Система-источник записи        | `mpay-api-gateway`     |
| `contract.createdByOp`       | String  | Нет            | Операция-источник записи       | `request: 12345`       |
| `contract.accountRequestID`  | String  | Да             | Идентификатор заявки на кредит | `12345`                |

> ℹ️ MAG не преобразует ответ Accounting Service: набор атрибутов договора задаётся внешним сервисом.

## Коды ответа
| Код ответа | Описание              | Причина                                 |
| ---------- | --------------------- | --------------------------------------- |
| `200`      | OK                    | Детали договора получены                |
| `400`      | BAD_REQUEST           | Параметры запроса не удалось разобрать  |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка API Accounting или чтения ответа |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Логика работы
1. **Приём и валидация:** MAG разбирает query-параметры в структуру запроса. Если разобрать не удалось — возвращает `400`.
2. **Внешний вызов:** передаёт идентификатор заявки в API Accounting.
3. **Формирование ответа:** возвращает ответ внешнего сервиса без преобразования, сохраняя его код ответа.

> ℹ️ В отличие от остальных методов группы, этот метод не проверяет наличие сессионных данных: идентификация выполняется на этапе проверки токена.

## Request
```bash
curl -X GET "https://gateway.direct-pay.ru/api/v1/contract?accountRequestID=12345" \
  -H "Authorization: Bearer <token>"
```

## Response
`200 OK`

```json
{
  "contract": {
    "bankContractNum": "OTP-2026-000123",
    "bankCode": "otp",
    "accountRequestID": "12345",
    "contractAmountKop": 15000000,
    "monthlyAmountKop": 1250000,
    "termMonth": 12,
    "status": "AGREEMENT_AUTORIZED"
  }
}
```
