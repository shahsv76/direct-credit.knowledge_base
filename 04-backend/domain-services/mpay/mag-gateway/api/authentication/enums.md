# ENUM и константы (Authentication)

| Название     | Значения                                   | Описание                          |
| ------------ | ------------------------------------------ | --------------------------------- |
| `Status`     | `VALID`, `EXPIRED`, `NOT_FOUND`, `BLOCKED` | Статусы проверки токена           |
| `NextAction` | `CONFIRM`, `AUTHORIZE`, `NONE`             | Следующие действия после проверки |
