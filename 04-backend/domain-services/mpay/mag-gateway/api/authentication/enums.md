# ENUM и константы (Authentication)

| Название     | Значения                                   | Описание                          |
| ------------ | ------------------------------------------ | --------------------------------- |
| `Status`     | `VALID`, `EXPIRED`, `NOT_FOUND`, `BLOCKED` | Статусы проверки токена           |
| `NextAction` | `CONFIRM`, `AUTHORIZE`, `NONE`             | Следующие действия после проверки |

## Партнёры

| Название       | Значение       | Описание                                                               |
| -------------- | -------------- | ---------------------------------------------------------------------- |
| `dcpay-mobile` | `dcpay-mobile` | Партнёр, для которого доступны короткая проверка токена и вход без OTP |

## Типы документов (СОПД)

Значения по умолчанию для списка `DOC_TYPES_LIST` (порядок определяет сортировку соглашений в ответе).

| Название                         | Описание                                  |
| -------------------------------- | ----------------------------------------- |
| `AGREEMENT_OPD_DIGITAL_SIGN`     | Согласие на обработку персональных данных |
| `AGREEMENT_BKI`                  | Согласие на запрос в БКИ                  |
| `AGREEMENT_ADVERTISING`          | Согласие на рекламные рассылки            |
| `AGREEMENT_PDN_CUSTOMER_SERVICE` | Согласие на обслуживание клиента          |

## AuthenticationPhaseOneBadResponse

Объект ошибки, который возвращается при превышении лимита запросов OTP вместе с кодом `403`.

| Название      | Тип     | Обязательность | Описание                                                         | Пример                       |
| ------------- | ------- | -------------- | ---------------------------------------------------------------- | ---------------------------- |
| `message`     | String  | Да             | Текст ошибки                                                     | `exceeded OTP request limit` |
| `blockToTime` | String  | Да             | Дата и время окончания блокировки (`YYYY-MM-DD HH:mm:ss.ffffff`) | `2026-10-24 09:30:00.000000` |
| `Status`      | Boolean | Да             | Признак успеха операции; при ошибке всегда `false`               | `false`                      |

> ℹ️ Время блокировки рассчитывается от `TimeBlockResend` часов (константа `TimeBlockResend = 24`).
