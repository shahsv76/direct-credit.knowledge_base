# POST /api/v2/authentication/forgot_password (MAG)

## Описание
| Тип запроса | Название метода | Описание метода                                                                                              | URL                                      | Тип  |
| ----------- | --------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------- | ---- |
| POST        | ForgotPassword  | Запускает восстановление пароля: сбрасывает PIN по токену, получает соглашения и отправляет OTP-код клиенту. | `/api/v2/authentication/forgot_password` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Body
| Название   | Тип    | Обязательность | Описание                                        | Пример          |
| ---------- | ------ | -------------- | ----------------------------------------------- | --------------- |
| `pinToken` | String | Да             | PIN-токен, по которому выполняется сброс пароля | `eyJhbGciOi...` |

## Выходные параметры
| Название     | Тип                                                  | Обязательность | Описание                                | Пример          |
| ------------ | ---------------------------------------------------- | -------------- | --------------------------------------- | --------------- |
| `xOTPToken`  | String                                               | Да             | Токен OTP-сессии для подтверждения кода | `eyJhbGciOi...` |
| `agreements` | Array<[PreAgreement](./general-dto.md#preagreement)> | Да             | Список соглашений (СОПД)                | `[{...}]`       |

## Коды ответа
| Код ответа | Описание              | Причина                                                     |
| ---------- | --------------------- | ----------------------------------------------------------- |
| `201`      | CREATED               | Пароль сброшен, OTP отправлен, соглашения получены          |
| `400`      | BAD_REQUEST           | Некорректное тело запроса                                   |
| `403`      | FORBIDDEN             | Доступ запрещён                                             |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка сброса пароля, получения соглашений или отправки OTP |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Логика работы
1. **Приём и валидация:** MAG принимает запрос и валидирует поле `pinToken`.
2. **Сброс пароля:** Вызывает Authentication Service (`/api/v3/forgot_password`) и получает данные клиента (`clientID`, `phone`, `partnerID`).
3. **Получение соглашений:** Запрашивает документы в Offer Service (`/v1/getCommonDocsInfoByDocTypes`) и сортирует их по `DOC_TYPES_LIST` (см. [ENUM](./enums.md#типы-документов-сопд)).
4. **Отправка OTP:** Вызывает OTP Service (`/otp/v2/send`) для отправки кода.
5. **Сохранение факта:** Вызывает Authentication Service (`/api/v3/fact_sms_send`), фиксируя отправку SMS.
6. **Формирование ответа:** Собирает `xOTPToken` и список соглашений и возвращает клиенту с кодом `201`.

## Request
```bash
curl -X POST "https://gateway.direct-pay.ru/api/v2/authentication/forgot_password" \
  -H "Content-Type: application/json" \
  -d '{ "pinToken": "eyJhbGciOi..." }'
```
