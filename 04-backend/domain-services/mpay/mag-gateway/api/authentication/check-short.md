# POST /authentication/check_short (MAG)

## Описание
| Тип запроса | Название метода | Описание метода                                                                                       | URL                           | Тип  |
| ----------- | --------------- | ----------------------------------------------------------------------------------------------------- | ----------------------------- | ---- |
| POST        | CheckTokenShort | Проверяет токен AUTH1 и для партнёра `dcpay-mobile` сразу формирует сессионный токен, минуя ввод OTP. | `/authentication/check_short` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Body
| Название                                                                              | Тип    | Обязательность | Описание                         | Пример                                                 |
| ------------------------------------------------------------------------------------- | ------ | -------------- | -------------------------------- | ------------------------------------------------------ |
| 🔗 [AuthenticationCheckTokenRequest](./general-dto.md#authenticationchecktokenrequest) | Object | Да             | Данные для проверки токена AUTH1 | `{ "secret": "dcpay-mobile", "token": "0abfb32e..." }` |

## Выходные параметры
| Название | Тип    | Обязательность | Описание                                                 | Пример          |
| -------- | ------ | -------------- | -------------------------------------------------------- | --------------- |
| `token`  | String | Да             | Сессионный токен (создаётся для партнёра `dcpay-mobile`) | `eyJhbGciOi...` |

## Коды ответа
| Код ответа | Описание              | Причина                                                       |
| ---------- | --------------------- | ------------------------------------------------------------- |
| `200`      | OK                    | Токен проверен, сессия сформирована                           |
| `400`      | BAD_REQUEST           | Не удалось прочитать тело запроса                             |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка проверки токена или создания сессии во внешнем сервисе |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Внешние сервисы
| Сервис                   | URL (env)            | Метод | Эндпоинт               |
| ------------------------ | -------------------- | ----- | ---------------------- |
| Authentication Service ⏳ | `AUTHENTICATION_URL` | POST  | `/api/v1/check_token`  |
| Authorization Service ⏳  | `AUTHORIZATION_URL`  | POST  | `/api/v1/create_token` |

## Метрика
| Параметр        | Значение                                                      |
| --------------- | ------------------------------------------------------------- |
| **Имя метрики** | `Login User` (`metrics.MetricLoginUser`)                      |
| **Топик**       | `auth`                                                        |
| **vendor**      | `mpay-api-gateway handler.Authentication.CheckTokenShort() N` |

## Логика работы
1. **Приём и валидация:** MAG принимает запрос и валидирует поля `secret` и `token`.
2. **Внешний вызов:** Вызывает Authentication Service (`/api/v1/check_token`) для проверки токена. При ошибке — метрика `Login User`, ответ 500.
3. **Создание сессии:** Если партнёр равен `dcpay-mobile` (см. [ENUM](./enums.md#партнёры)), вызывает Authorization Service (`/api/v1/create_token`) и получает сессионный токен.
4. **Формирование ответа:** Возвращает сессионный токен клиенту.

## Request
```bash
curl -X POST "https://gateway.direct-pay.ru/authentication/check_short" \
  -H "Content-Type: application/json" \
  -d '{ "secret": "dcpay-mobile", "token": "0abfb32e303d35bc68cb3e70018c6551" }'
```
