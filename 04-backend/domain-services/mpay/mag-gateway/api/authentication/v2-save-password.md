# POST /api/v2/authentication/save_password (MAG)

## Описание
| Тип запроса | Название метода | Описание метода                                                                                     | URL                                    | Тип  |
| ----------- | --------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------- | ---- |
| POST        | SavePassword    | Сохраняет пароль (PIN) клиента на основании нового PIN-токена, полученного после подтверждения OTP. | `/api/v2/authentication/save_password` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Body
| Название      | Тип    | Обязательность | Описание                                    | Пример          |
| ------------- | ------ | -------------- | ------------------------------------------- | --------------- |
| `newPinToken` | String | Да             | Новый PIN-токен (получен из `phase_otp` v2) | `eyJhbGciOi...` |
| `password`    | String | Да             | Пароль (PIN-код) клиента                    | `1234`          |

## Выходные параметры
| Название      | Тип    | Обязательность | Описание                                    | Пример          |
| ------------- | ------ | -------------- | ------------------------------------------- | --------------- |
| `newPinToken` | String | Да             | PIN-токен, подтверждающий сохранение пароля | `eyJhbGciOi...` |

## Коды ответа
| Код ответа | Описание              | Причина                                     |
| ---------- | --------------------- | ------------------------------------------- |
| `201`      | CREATED               | Пароль успешно сохранён                     |
| `400`      | BAD_REQUEST           | Некорректное тело запроса                   |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка сохранения пароля во внешнем сервисе |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Внешние сервисы
| Сервис                   | URL (env)            | Метод | Эндпоинт               |
| ------------------------ | -------------------- | ----- | ---------------------- |
| Authentication Service ⏳ | `AUTHENTICATION_URL` | POST  | `/api/v3/new_password` |

## Метрика
| Параметр        | Значение                                                   |
| --------------- | ---------------------------------------------------------- |
| **Имя метрики** | `Login User` (`metrics.MetricLoginUser`)                   |
| **Топик**       | `auth`                                                     |
| **vendor**      | `mpay-api-gateway handler.Authentication.SavePassword() N` |

## Логика работы
1. **Приём и валидация:** MAG принимает запрос и валидирует поля `newPinToken` и `password`.
2. **Внешний вызов:** Вызывает Authentication Service (`/api/v3/new_password`) для сохранения пароля. При ошибке — ответ 500.
3. **Формирование ответа:** Возвращает результат сохранения пароля клиенту с кодом `201`.

## Request
```bash
curl -X POST "https://gateway.direct-pay.ru/api/v2/authentication/save_password" \
  -H "Content-Type: application/json" \
  -d '{ "newPinToken": "eyJhbGciOi...", "password": "1234" }'
```
