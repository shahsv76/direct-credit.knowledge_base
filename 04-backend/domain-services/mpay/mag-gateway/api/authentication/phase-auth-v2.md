# POST /api/v2/authentication/phase_auth (MAG)

## Описание
| Тип запроса | Название метода | Описание метода                                                                              | URL                                 | Тип  |
| ----------- | --------------- | -------------------------------------------------------------------------------------------- | ----------------------------------- | ---- |
| POST        | PhaseAuth       | Авторизует клиента по PIN-коду: проверяет пароль по PIN-токену и формирует сессионный токен. | `/api/v2/authentication/phase_auth` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Body
| Название   | Тип    | Обязательность | Описание                                  | Пример          |
| ---------- | ------ | -------------- | ----------------------------------------- | --------------- |
| `pinToken` | String | Да             | PIN-токен, полученный на первой фазе (v2) | `eyJhbGciOi...` |
| `password` | String | Да             | Пароль (PIN-код) клиента                  | `1234`          |

## Выходные параметры
| Название | Тип    | Обязательность | Описание                                 | Пример          |
| -------- | ------ | -------------- | ---------------------------------------- | --------------- |
| `token`  | String | Да             | Сессионный токен для дальнейших запросов | `eyJhbGciOi...` |

## Коды ответа
| Код ответа | Описание              | Причина                                    |
| ---------- | --------------------- | ------------------------------------------ |
| `201`      | CREATED               | Пароль верный, сессия создана              |
| `400`      | BAD_REQUEST           | Некорректное тело запроса                  |
| `403`      | FORBIDDEN             | Неверный пароль / доступ запрещён          |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка проверки пароля или создания токена |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

| Authorization Service ⏳  | `AUTHORIZATION_URL`  | POST  | `/api/v1/create_token`   |

## Метрика
| Параметр        | Значение                                                     |
| --------------- | ------------------------------------------------------------ |
| **Имя метрики** | [`Login User`](../../metrics.md) (`metrics.MetricLoginUser`) |
| **Топик**       | `auth`                                                       |
| **vendor**      | `mpay-api-gateway handler.Authentication.PhaseAuth() N`      |

## Логика работы
1. **Приём и валидация:** MAG принимает запрос и валидирует поля `pinToken` и `password`.
2. **Проверка пароля:** Вызывает Authentication Service (`/api/v3/check_password`). При ошибке — ответ 500.
3. **Создание сессии:** Из результата проверки получает `clientID`, `phone`, `partnerID` и вызывает Authorization Service (`/api/v1/create_token`).
4. **Формирование ответа:** Возвращает сессионный токен клиенту с кодом `201`.

## Request
```bash
curl -X POST "https://gateway.direct-pay.ru/api/v2/authentication/phase_auth" \
  -H "Content-Type: application/json" \
  -d '{ "pinToken": "eyJhbGciOi...", "password": "1234" }'
```
