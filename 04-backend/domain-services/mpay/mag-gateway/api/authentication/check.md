# POST /authentication/check (MAG)

## Описание
| Тип запроса | Название метода | Описание метода                                                                                      | URL                     | Тип  |
| ----------- | --------------- | ---------------------------------------------------------------------------------------------------- | ----------------------- | ---- |
| POST        | CheckToken      | Проверяет токен AUTH1, полученный от BFF, и по его результатам инициирует отправку OTP-кода клиенту. | `/authentication/check` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Body
| Название                                                                              | Тип    | Обязательность | Описание                         | Пример                                                 |
| ------------------------------------------------------------------------------------- | ------ | -------------- | -------------------------------- | ------------------------------------------------------ |
| 🔗 [AuthenticationCheckTokenRequest](./general-dto.md#authenticationchecktokenrequest) | Object | Да             | Данные для проверки токена AUTH1 | `{ "secret": "dcpay-mobile", "token": "0abfb32e..." }` |

## Выходные параметры
| Название                                                  | Тип    | Обязательность | Описание                                                       | Пример                                                     |
| --------------------------------------------------------- | ------ | -------------- | -------------------------------------------------------------- | ---------------------------------------------------------- |
| 🔗 [OtpCreateResponse](./general-dto.md#otpcreateresponse) | Object | Да             | Ответ OTP-сервиса: код ответа, токен OTP-сессии и текст ошибки | `{ "code": 201, "xOTPToken": "eyJhbGciOi...", "err": "" }` |

## Коды ответа
| Код ответа | Описание              | Причина                                                    |
| ---------- | --------------------- | ---------------------------------------------------------- |
| `201`      | CREATED               | Токен проверен, OTP-сессия создана                         |
| `400`      | BAD_REQUEST           | Не удалось прочитать тело запроса                          |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка проверки токена или создания OTP во внешнем сервисе |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Внешние сервисы
| Сервис                   | URL (env)            | Метод | Эндпоинт              |
| ------------------------ | -------------------- | ----- | --------------------- |
| Authentication Service ⏳ | `AUTHENTICATION_URL` | POST  | `/api/v1/check_token` |
| OTP Service ⏳            | `OTP_URL`            | POST  | `/otp/v2/send`        |

## Метрика
| Параметр        | Значение                                                     |
| --------------- | ------------------------------------------------------------ |
| **Имя метрики** | [`Login User`](../../metrics.md) (`metrics.MetricLoginUser`) |
| **Топик**       | `auth`                                                       |
| **vendor**      | `mpay-api-gateway handler.Authentication.CheckToken() N`     |

## Логика работы
1. **Приём и валидация:** MAG принимает запрос, валидирует поля `secret` и `token`.
2. **Внешний вызов:** Вызывает Authentication Service (`/api/v1/check_token`). При ошибке — метрика `Login User`, ответ 500.
3. **Создание OTP:** По данным клиента (`clientID`, `phone`) вызывает OTP Service (`/otp/v2/send`). При ошибке — метрика `Login User`, ответ 500.
4. **Формирование ответа:** Возвращает ответ OTP-сервиса (токен OTP-сессии) клиенту.

## Request
```bash
curl -X POST "https://gateway.direct-pay.ru/authentication/check" \
  -H "Content-Type: application/json" \
  -d '{ "secret": "dcpay-mobile", "token": "0abfb32e303d35bc68cb3e70018c6551" }'
```
