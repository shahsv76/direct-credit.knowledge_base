# POST /api/v2/authentication/save_password_retype (MAG)

## Описание
| Тип запроса | Название метода    | Описание метода                                                                                      | URL                                           | Тип  |
| ----------- | ------------------ | ---------------------------------------------------------------------------------------------------- | --------------------------------------------- | ---- |
| POST        | SavePasswordRetype | Проверяет повторный ввод пароля, сохраняет его и сразу формирует сессионный токен для входа клиента. | `/api/v2/authentication/save_password_retype` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Body
| Название                                                      | Тип    | Обязательность | Описание                                                                      | Пример                                                   |
| ------------------------------------------------------------- | ------ | -------------- | ----------------------------------------------------------------------------- | -------------------------------------------------------- |
| 🔗 [SavePasswordRequest](./general-dto.md#savepasswordrequest) | Object | Да             | Новый PIN-токен, полученный после `phase_otp` v2, и повторно введённый пароль | `{ "newPinToken": "eyJhbGciOi...", "password": "1234" }` |

## Выходные параметры
| Название | Тип    | Обязательность | Описание                                 | Пример          |
| -------- | ------ | -------------- | ---------------------------------------- | --------------- |
| `token`  | String | Да             | Сессионный токен для дальнейших запросов | `eyJhbGciOi...` |

## Коды ответа
| Код ответа | Описание              | Причина                                                         |
| ---------- | --------------------- | --------------------------------------------------------------- |
| `201`      | CREATED               | Пароль подтверждён, сессия создана                              |
| `400`      | BAD_REQUEST           | Некорректное тело запроса или ошибка проверки/сохранения пароля |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка создания сессионного токена                              |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Метрика
| Параметр        | Значение                                                         |
| --------------- | ---------------------------------------------------------------- |
| **Имя метрики** | [`Login User`](../../metrics.md) (`metrics.MetricLoginUser`)     |
| **Топик**       | `auth`                                                           |
| **vendor**      | `mpay-api-gateway handler.Authentication.SavePasswordRetype() N` |

## Логика работы
1. **Приём и валидация:** MAG принимает запрос и валидирует поля `newPinToken` и `password`.
2. **Проверка и сохранение пароля:** Вызывает Authentication Service (`/api/v3/check_retype_password`). При ошибке — ответ 400.
3. **Создание сессии:** Вызывает Authorization Service (`/api/v1/create_token`), передавая `clientID`, `phone` и `partnerID`, полученные из результата проверки пароля.
4. **Формирование ответа:** Возвращает сессионный токен клиенту с кодом `201`.

## Request
```bash
curl -X POST "https://gateway.direct-pay.ru/api/v2/authentication/save_password_retype" \
  -H "Content-Type: application/json" \
  -d '{ "newPinToken": "eyJhbGciOi...", "password": "1234" }'
```
