# POST /authentication/resend (MAG)

## Описание
| Тип запроса | Название метода | Описание метода                                                                                    | URL                      | Тип  |
| ----------- | --------------- | -------------------------------------------------------------------------------------------------- | ------------------------ | ---- |
| POST        | Resend          | Повторно отправляет OTP-код по существующей OTP-сессии с предварительной проверкой блокировки SMS. | `/authentication/resend` | SYNC |

## Входные параметры
### Header
| Название                                           | Тип | Обязательность | Описание           | Пример |
| -------------------------------------------------- | --- | -------------- | ------------------ | ------ |
| 🔗 [Общие заголовки (MAG)](../../common-headers.md) | —   | —              | См. общую страницу | —      |

### Body
| Название    | Тип    | Обязательность | Описание                                                   | Пример          |
| ----------- | ------ | -------------- | ---------------------------------------------------------- | --------------- |
| `xOTPToken` | String | Да             | Токен OTP-сессии, по которому требуется повторная отправка | `eyJhbGciOi...` |

## Выходные параметры
| Название    | Тип     | Обязательность | Описание                               | Пример          |
| ----------- | ------- | -------------- | -------------------------------------- | --------------- |
| `code`      | Integer | Да             | Внутренний код ответа OTP-сервиса      | `201`           |
| `xOTPToken` | String  | Да             | Токен OTP-сессии                       | `eyJhbGciOi...` |
| `err`       | String  | Нет            | Текст ошибки OTP-сервиса (при наличии) | `""`            |

> ⚠️ При превышении лимита запросов возвращается объект ошибки [`AuthenticationPhaseOneBadResponse`](./enums.md#authenticationphaseonebadresponse) с кодом `403`.

## Коды ответа
| Код ответа | Описание              | Причина                                                                |
| ---------- | --------------------- | ---------------------------------------------------------------------- |
| `201`      | CREATED               | Код повторно отправлен                                                 |
| `400`      | BAD_REQUEST           | Не удалось прочитать тело запроса                                      |
| `403`      | FORBIDDEN             | Превышен лимит запросов OTP (блокировка на `TimeBlockResend` часов)    |
| `500`      | INTERNAL_SERVER_ERROR | Ошибка проверки блокировки, отправки OTP или сохранения факта отправки |

🔗 *Все общие коды ошибок см. на странице [Общие ошибки (MAG)](../../common-errors.md).*

## Внешние сервисы

| Authentication Service ⏳ | `AUTHENTICATION_URL` | POST  | `/api/v3/fact_sms_send`          |

## Логика работы
1. **Приём и валидация:** MAG принимает запрос и валидирует поле `xOTPToken`. Если валидация не прошла — возвращается код `400` BAD_REQUEST.
2. **Проверка блокировки:** Вызывает Authentication Service (`/api/v3/check_sms_block_resend`). При ошибке — ответ 500.
3. **Внешний вызов:** Вызывает OTP Service (`/otp/resend`) для повторной отправки кода. Если OTP-сервис вернул `429` или `460` — MAG отвечает `403` с объектом [`AuthenticationPhaseOneBadResponse`](./enums.md#authenticationphaseonebadresponse), время блокировки — `TimeBlockResend` часов.
4. **Сохранение факта:** Вызывает Authentication Service (`/api/v3/fact_sms_send`), чтобы зафиксировать отправку SMS.
5. **Формирование ответа:** Возвращает результат повторной отправки клиенту.

## Request
```bash
curl -X POST "https://gateway.direct-pay.ru/authentication/resend" \
  -H "Content-Type: application/json" \
  -d '{ "xOTPToken": "eyJhbGciOi..." }'
```
