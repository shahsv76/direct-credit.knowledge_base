# Общие заголовки BFF (mPay)

Все методы BFF-слоя (front-api) используют единый набор HTTP-заголовков для аутентификации и передачи данных.

| Название       | Тип    | Обязательность | Описание                                                                                                                | Пример                             |
| -------------- | ------ | -------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| `Content-Type` | String | Да             | Тип передаваемых данных. Для всех методов BFF используется JSON.                                                        | `application/json`                 |
| `auth`         | String | Да             | Токен сессии (Bearer). Выдается на предыдущих шагах (например, после `auth/check`).                                     | `Bearer cqrc50ho8h...`             |
| `Cookie`       | String | Да             | Содержит идентификаторы сессии (`PHPSESSID`), а также токены систем аналитики и антифрода (Яндекс.Метрика, JuicyScore). | `PHPSESSID=...; pixel_sess_id=...` |
| `User-Agent`   | String | Да             | Данные браузера или устройства клиента. Используется для аналитики и антифрода.                                         | `Mozilla/5.0...`                   |

**Примечание:** Остальные заголовки (`accept`, `origin`, `referer`, `sec-fetch-*`, `sec-ch-ua-*`) проставляются браузером или мобильным приложением автоматически. Фронтенд-разработчику не нужно управлять ими вручную.
