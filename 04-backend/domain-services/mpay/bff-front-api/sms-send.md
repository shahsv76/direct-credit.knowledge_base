# POST sms/send (BFF)

## Описание
| Тип запроса | Название метода | Описание метода                                                                                                        | URL                               | Тип  |
| ----------- | --------------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------- | ---- |
| POST        | sms/send        | Отправка СМС-кода для подтверждения подписания. Возвращает статус отправки и таймер блокировки для повторного запроса. | `/api/widget.php?action=sms/send` | SYNC |

## Входные параметры
### Header
| Название                                     | Тип | Обязательность | Описание                                      |
| -------------------------------------------- | --- | -------------- | --------------------------------------------- |
| 🔗 [Общие заголовки BFF](./common-headers.md) | —   | —              | См. общую страницу (включая `auth`, `Cookie`) |

### URL (params)
| Название   | Тип    | Обязательность | Описание            | Пример        |
| ---------- | ------ | -------------- | ------------------- | ------------- |
| `action`   | String | Да             | Имя экшена          | `sms/send`    |
| `json`     | String | Да             | Флаг формата ответа | `Y`           |
| `order_id` | String | Да             | ID заказа           | `0abfb32e...` |

### Body
| Название       | Тип     | Обязательность | Описание                            | Пример           |
| -------------- | ------- | -------------- | ----------------------------------- | ---------------- |
| `phone_mobile` | String  | Да             | Маскированный номер телефона        | `(***) ***-2211` |
| `sms_mode`     | String  | Да             | Режим отправки (первичная отправка) | `first`          |
| `isBotEnabled` | Boolean | Да             | Флаг активности бота                | `false`          |

## Выходные параметры
| Название    | Тип     | Обязательность | Описание                                                    | Пример |
| ----------- | ------- | -------------- | ----------------------------------------------------------- | ------ |
| `result`    | Boolean | Да             | Флаг успешной отправки                                      | `true` |
| `isAttempt` | Boolean | Да             | Флаг, что это попытка отправки                              | `true` |
| `delay`     | Number  | Да             | Время в секундах, на которое блокируется повторная отправка | `60`   |

🔗 Все коды ошибок описаны на странице [Общие коды ответов BFF](./common-errors.md).

## Логика работы
1. **Аутентификация:** BFF валидирует заголовок `auth` (Bearer-токен).
2. **Отправка СМС:** BFF обращается к внутреннему сервису (⏳ *предположительно `mpay-SMS-gate` или `mpay-OTP`*) для генерации и отправки кода на номер `phone_mobile`.
3. **Формирование ответа:** BFF возвращает `result: true` и `delay: 60`, на основе которого фронтенд запускает таймер блокировки кнопки «Отправить СМС-код» на 60 секунд.

## Пример
### Request
```bash
curl -X POST "https://lk-test.direct-credit.ru/api/widget.php?action=sms/send&json=Y&order_id=0abfb32e303d35bc68cb3e70018c6551" \
  -H "auth: Bearer cqrc50ho8h9233eg685hoe33h1" \
  -H "Content-Type: application/json" \
  -d '{
    "phone_mobile": "(***) ***-2211",
    "sms_mode": "first",
    "isBotEnabled": false
  }'
