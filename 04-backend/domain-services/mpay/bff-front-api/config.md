# POST config (BFF)

## Описание
| Тип запроса | Название метода | Описание метода                                                                                                      | URL                             | Тип  |
| ----------- | --------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------- | ---- |
| POST        | config          | Загрузка конфигурации виджета. Определяет брендирование, номер заказа, общую сумму, а также пути к логотипам банков. | `/api/widget.php?action=config` | SYNC |

## Выходные параметры
| Название                  | Тип    | Описание                                                               |
| ------------------------- | ------ | ---------------------------------------------------------------------- |
| `colorSchemeRelativePath` | String | Путь к CSS-файлу с цветовой схемой бренда                              |
| `orderNumber`             | String | Номер заказа (например, `ORD1291627918`)                               |
| `totalPrice`              | Number | Общая сумма заказа                                                     |
| `banksLogoRelativePath`   | Object | Объект с путями к логотипам банков (ключ - код банка, значение - путь) |

## Логика работы
1. BFF аутентифицирует запрос.
2. Собирает настройки из конфигурации партнера (по `order_id`).
3. Возвращает объект конфигурации.
