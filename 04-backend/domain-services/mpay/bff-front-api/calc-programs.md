# POST calc/programs (BFF)

## Описание
| Тип запроса | Название метода | Описание метода                                                                                                                                   | URL                                    | Тип  |
| ----------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- | ---- |
| POST        | calc/programs   | Получение данных для калькулятора и списка банков. Возвращает доступные сроки, ежемесячные платежи, список банков-партнеров и доступные продукты. | `/api/widget.php?action=calc/programs` | SYNC |

## Выходные параметры (Ключевые блоки)
| Название           | Тип    | Описание                                                                                |
| ------------------ | ------ | --------------------------------------------------------------------------------------- |
| `conditions`       | Object | Ограничения по сумме, сроку и первоначальному взносу                                    |
| `banks_collection` | Object | Список банков-партнеров с их настройками (ИНН, БИК, лицензии и т.д.)                    |
| `paymentMethods`   | Array  | Доступные кредитные программы (`classic`, `promo` и т.д.) с массивом кредитов (`loans`) |

## Логика работы
1. BFF аутентифицирует запрос.
2. Обращается к сервису ⏳ `mpay-scoring` или БД для получения актуальных программ банков.
3. Возвращает массив кредитных программ.
